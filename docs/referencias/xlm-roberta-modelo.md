# XLM-RoBERTa — base multilingüe

**Cita:** Alexis Conneau et al., *Unsupervised Cross-lingual Representation Learning at Scale*, [arXiv:1911.02116](https://arxiv.org/abs/1911.02116), v2, 8 de abril de 2020. **Clave:** `XLMR2020`. **Consulta:** 2026-11-18. **PDF local:** no descargado; se consultó el registro primario del artículo.

El resumen presenta XLM-R como modelo multilingüe preentrenado mediante lenguaje enmascarado. La referencia identifica la familia del clasificador; no valida valoración política dirigida, español peruano ni indicadores afectivos locales.

El experimento usa `FacebookAI/xlm-roberta-base`, revisión `e73636d4f797dec63c3081bb6ed5c7b0bb3f2089`, y capacidad efectiva de 512 tokens registrada por la ejecución. No se transfieren puntuaciones de sus benchmarks al estudio.
