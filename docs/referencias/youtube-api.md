# YouTube Data API — documentación de hilos

**Fuente primaria:** Google for Developers, [CommentThreads](https://developers.google.com/youtube/data/reference/rest/v3/commentThreads). **Clave:** `YoutubeThreads`. **Consulta:** 2026-11-18. **PDF local:** no aplica; documentación web.

La descripción del recurso indica que un hilo incluye el comentario principal y puede incluir solo parte de sus respuestas; para todas las respuestas remite a `comments.list`. Sustenta la captura paginada y la recuperación complementaria por padre. No permite reconstruir comentarios eliminados, inferir destinatarios discursivos ni convertir el marco seleccionado en un censo de YouTube.
